# EPICEVENTZ - Unified B2B2C Event Management Platform

> **Cognizant NPN Salesforce Hackathon 2027 Submission**

## Executive Summary
EPICEVENTZ is an enterprise-grade B2B2C Event Management and Ticketing Platform built on Salesforce. It bridges the gap between **Event Organizers** (B2B internal operations) and **Attendees** (B2C customer experience), providing end-to-end automation, capacity control, real-time ticket inventory safety, automated payments, AI feedback intelligence, and executive analytics.

## Core Architectural Layers
1. **Data Model:** Custom & Standard Objects (`Event__c`, `Venue__c`, `Ticket_Type__c`, `Registration__c`, `Payment__c`, `Feedback__c`, `Case`, `Account`, `Contact`).
2. **Security & Access:** OWD, Role Hierarchy, Profiles, Permission Sets, Field-Level Security.
3. **Business Process Automation:** Record-Triggered Flows, Approval Processes, Validation Rules, Formula Fields.
4. **Apex & Asynchronous Services:** Bulkified Apex Trigger Framework, Queueable Apex, Batch Apex, Scheduled Automation.
5. **Experience & UI:** Lightning Web Components (LWC) for Event Discovery, Booking, and Dashboards.
6. **Integration & Events:** Custom REST APIs, External Credentials/Named Credentials, Platform Events.
7. **AI & Intelligence:** Agentforce / AI-Assisted Feedback Intelligence & Event Guardian Health Engine.
8. **Analytics:** Native Salesforce Reports & Dashboards for Organizers and System Admins.
